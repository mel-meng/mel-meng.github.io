InfoWorks ICM Cloud — New Customer Setup Manual

A practical guide for small project teams that want one shared cloud model, full modeling access for the modeler, and simple review access for GIS, engineering, clients, and other stakeholders.

Working draft: Items marked MISSING or VERIFY still need to be confirmed before this manual is issued to customers.

1. What this setup is for

A typical small ICM project may have only one or two people who build and run the model, while several other people need to see the model and results. Those reviewers may include GIS staff, engineering/design teams, clients, managers, or other project stakeholders.

ICM Cloud gives the project one shared source. Instead of repeatedly creating screenshots, PDFs, PowerPoints, or separate copies of the model just so other people can review the work, the model can be stored in the cloud and the right people can be given access when they need it.

A familiar way to think about it: the Hub is similar to a shared workspace, and Projects are similar to shared folders used to control which groups can access different work. The cloud permission controls what you can reach; the software you use controls what you can do with it. Autodesk Help: cloud access basics ↗
One shared sourceModels and results live in the cloud, so authorized users see the same current project information.
Right tool for the roleThe modeler uses full InfoWorks ICM. Review-only users use the free InfoWorks ICM Viewer.
Project Admin controls accessThe Project Admin decides who is a member of the Project and updates membership as the project changes.

For most small customers: keep the structure simple. Use the existing Autodesk Team, create one Hub in the appropriate region, and use Projects to separate jobs or groups that should have different access. Autodesk Help: Hubs and Regions ↗

4. IT / Cloud Admin — set up the cloud environment

The IT / Cloud Admin establishes the shared environment. After the Hub, Project, and initial modeler access are ready, most day-to-day membership work can be handled by the Project Admin.

4.1 Create the Hub and choose the Region

  1. Sign in to Autodesk Account.
  2. Open Products and Services, then open Hubs. Autodesk Help ↗
  3. Confirm the correct Autodesk Team is selected. For a small customer, normally use the existing Team rather than creating additional Teams.
  4. Select Create hub, then choose Info360.
  5. Enter the Hub name.
  6. Select the appropriate Data region.
  7. Select Create & Activate.
Official help: Create Hub and Activate Subscription ↗ Getting started with cloud access ↗

4.2 Create the Project

  1. From the Hub, select Administration. This opens the Project administration environment.
  2. Select Create project. Autodesk Help: Project Administration ↗
  3. Enter a Project name and select the correct Hub.
  4. Complete any other Project fields required by your organization.
  5. Select Create project.

If you are already a Project Admin and do not need to manage the Hub, you can open the Autodesk project administration page ↗ directly.

Official reference: Autodesk Project Administration ↗

VERIFY — Project creation fields Confirm which Project Type and other optional fields should be recommended for a standard ICM customer setup. The current source shows an example, but does not define a universal customer standard.

4.3 Add the modeler as Project Admin

  1. Open the new Project and go to Members.
  2. Select Add members. Autodesk Help: Manage Project Members ↗
  3. Enter the modeler's email address and continue.
  4. Select the appropriate model role. For a modeler who needs to edit, use the editing role appropriate to your environment.
  5. Set Access Level to Project administrator.
  6. Enable Info360 Model.
  7. Send the invitation.
VERIFY — Modeler role label The current screenshots show both Model Reader and Model Editor. Confirm the exact recommended role for a full ICM modeler in the current production environment before customer release.

4.4 Confirm InfoWorks ICM software and licensing

The modeler needs the full InfoWorks ICM desktop application and an appropriate license to edit models and run simulations. Autodesk Account administrators assign product access through User Management. Autodesk Help: Assign product access ↗

MISSING — Full ICM setup Add the customer-facing steps for assigning/checking the modeler's InfoWorks ICM license and installing the desktop application on a new computer.

5. Modeler / Project Admin — create the cloud database

5.1 Open the Project

Use the Autodesk account that was added to the Project. If an invitation email was sent, open it and sign in with the same email address.

5.2 Create a new cloud database

  1. Open InfoWorks ICM.
  2. Select File → Open → Open/Create database. Autodesk ICM Help: Create a Database ↗
  3. Select Cloud.
  4. Select the correct Hub and Project.
  5. Next to Database, select New.
  6. Enter the database name.
  7. Select the database version.
  8. Select OK to create the database.
Official help: Create a Database — InfoWorks ICM Help ↗ Cloud database setup support article ↗

5.3 Build or place the model in the database

For a new project, continue building the model in the cloud database using the normal InfoWorks ICM modeling workflow.

MISSING — Existing model migration Add a verified procedure for a customer who already has an existing standalone, transportable, or workgroup database and needs to move or copy that model into the new cloud Project. Related official reference: InfoWorks ICM Help — Cloud Databases ↗

6. Project Admin — add and manage Project users

Project membership is the main control for sharing the cloud model. Add people when they need access, update their role if their responsibility changes, and remove them when access is no longer required.

6.1 Add a review-only user

  1. Open the Project and go to Members.
  2. Select Add members. Autodesk Help: Manage Project Members ↗
  3. Enter the reviewer's email address.
  4. Set Role to Model Reader.
  5. Set Access Level to Project member.
  6. Enable Info360 Model.
  7. Send the invitation.

This same review-only pattern can be used for GIS, engineering, client, or other stakeholders who need to inspect the model and results but do not need to edit the model.

VERIFY — Internal vs. external invitations Confirm whether users inside and outside the customer's organization follow the same invitation and acceptance sequence, including any additional external-user prompts.

6.2 Add, change, or remove access during the project

  • Add new members when another group needs access.
  • Change a member's role or access level when responsibilities change.
  • Remove members who no longer need the Project. Autodesk Help ↗
  • Keep Project Administrator access limited to the people who actually need to manage the Project.

7. Reviewer — install Viewer and open the model

7.1 Use the same email address that was invited

The reviewer should use an Autodesk account associated with the same email address that the Project Admin added to the Project. If the reviewer does not already have an Autodesk account, create one with that email address.

7.2 Download and install the free InfoWorks ICM Viewer

For a reviewer who does not need the full modeling application, use the free InfoWorks ICM Viewer.

  1. Open the InfoWorks ICM Viewer download page ↗.
  2. Download the Viewer installer. Autodesk's download page lists current available versions and notes that administrator rights are required for installation. Official Viewer download & install guidance ↗
  3. Install the Viewer on the reviewer's computer.
  4. At first launch, sign in with the Autodesk account that was invited to the Project.
Additional Autodesk references: Viewer availability ↗ Installing newer Viewer versions ↗
VERIFY — Viewer versions and cloud access The working material includes version-specific notes about when the free Viewer became available and which versions can access cloud databases without an assigned ICM seat. Verify the current supported versions before publishing this section.

7.3 First sign-in

  1. Start InfoWorks ICM Viewer.
  2. When the Autodesk sign-in prompt appears, continue with browser sign-in. Autodesk Viewer guidance ↗
  3. Sign in with the invited Autodesk account.
  4. When the browser confirms that sign-in is complete, return to the Viewer.

7.4 Open the shared cloud database

  1. In Viewer, select Open database. InfoWorks ICM Help: Cloud Databases ↗
  2. Select the cloud Hub.
  3. Select the Project.
  4. Select the database.
  5. Select OK.

7.5 Confirm the reviewer is ready

At minimum, confirm that the reviewer can see the intended Project, open the intended database, and view the information needed for the project review.

MISSING — Standard Viewer validation checklist Define the exact two or three review actions that should be tested during onboarding, for example opening a network, inspecting an object, and displaying an existing result.

8. End of project

At the end of the project, the Project Admin should review who still needs access.

  • Remove external reviewers who no longer need access. Autodesk Help: Manage Project Members ↗
  • Remove internal users who no longer need the Project.
  • Remove unnecessary Project Administrator rights.
  • Confirm who should retain long-term access.
  • Confirm the final database/model is stored in the intended Project.
VERIFY — Project archival / closeout Decide whether the customer manual should include a formal Autodesk Project archival or long-term retention procedure beyond membership cleanup.

9. Optional — cloud simulation usage

For a small team running a normal number of project simulations, cloud simulation capacity is generally a secondary consideration. If a workflow requires unusually large numbers of concurrent runs, optimization/automation, long-running simulations, or substantial 2D computation, review the expected capacity needs separately. Autodesk Help explains that cloud-simulation quota affects parallel processing behavior and that work can continue sequentially after the quota is exceeded. InfoWorks ICM Help: Runs ↗

Check usage

  1. Sign in to Autodesk Account.
  2. Open Reporting.
  3. Open Resource and API usage.
  4. Review InfoWorks Cloud Simulation Hours.

Official references: InfoWorks ICM Help — Runs ↗ · InfoWorks ICM cloud capacity FAQ ↗

VERIFY — Current quota, capacity, and commercial rules Do not publish numeric quotas, pricing examples, or concurrency rules until the current Autodesk policy has been verified.

10. Troubleshooting

I cannot see the Administration link

  • Refresh the Hubs page.
  • Confirm the correct Team is selected.
  • Confirm that your Autodesk account has the required Hub administration rights. Autodesk Help ↗

I cannot see the Project

  • Confirm that the Project Admin added the same email address you are using to sign in.
  • Confirm the invitation was sent.
  • Confirm you are signed in with the correct Autodesk account.
  • Review the Project membership in Project Admin. Autodesk Help ↗

Viewer signs in, but I cannot see the database

  • Confirm you are a member of the correct Project.
  • Confirm Info360 Model was enabled for your Project membership.
  • Confirm you are using the email address that was invited.
  • Ask the Project Admin to verify the Project membership and role.

I need to edit or run simulations

The free Viewer is for review-only workflows. Contact the Project Admin / IT Admin if you need the full InfoWorks ICM application and license.
