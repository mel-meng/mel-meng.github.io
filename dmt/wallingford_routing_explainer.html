What the tool is showing

The reservoirs receive rainfall excess, not raw rainfall. First, rainfall passes through initial losses and a runoff-volume model. The result is an effective runoff rate, qin, that keeps falling into Reservoir 1 during the storm.

At the same timestep, the rainfall intensity also changes k. This is the key idea: the inflow to the first reservoir changes with rainfall excess, and the release rate from both reservoirs changes with rainfall intensity.

Geometry is mostly fixed for a surface. Area and slope estimate Cbase. The ICM runoff routing value R is the calibration multiplier that creates Cused. Rainfall intensity is dynamic. It sets i*, then k. Heavy rainfall makes k smaller, so the same storage depth releases more flow. Light rainfall makes k larger, so the reservoirs drain more slowly.

The curve insight: small rain drains slowly; active rain drains faster.

When rainfall intensity is very low, k is large, so the reservoirs release slowly. Once rainfall becomes meaningful, k drops quickly. That is the model's way of saying that shallow, disconnected trickles become connected overland/gully flow during active rainfall.

The curve then flattens at high intensity. Very heavy rain still makes k smaller, but not infinitely small, so the two reservoirs still provide attenuation and lag.

qin

Rainfall excess entering Reservoir 1. In the tool it is rainfall × excess factor; in ICM it comes from the selected runoff-volume method.

A

Surface area. It affects the estimated geometry coefficient Cbase and converts depth storage to volume: V = (S/1000) × A when S is in mm.

R

ICM runoff routing value in Rel mode. This is the main calibration knob: Cused = R × Cbase. Larger R gives more lag and attenuation.

Sslope

Ground slope used in the C equation. This is not the same as S1 or S2, which are storage depths.

k

The current storage/delay coefficient. Larger k means slower release. Smaller k means faster release.

S1

Storage depth/head in Reservoir 1. It fills from qin and drains as q1 = S1/k.

S2

Storage depth/head in Reservoir 2. It fills from q1 and drains as q2 = S2/k.

q1

Outflow from Reservoir 1. This is also the inflow to Reservoir 2.

q2

Final routed runoff leaving Reservoir 2. This is the smoothed and delayed response delivered to the node.
