NAPI / API30 made simple

NAPI is just a weighted 30-day rainfall average.

The model looks back across recent days. Rain from today or yesterday counts a lot. Rain from three weeks ago counts less. That is the whole idea.

The simple equation
Daily NAPI piece = max(P − E, 0) × weight

Then add the 30 pieces together. The weight is controlled by k: a high k remembers old rain longer; a low k forgets it quickly.

Tell the story first

Do not start with the formula. Start with rainfall history.

Start with constant rain

Put the same rain on every day. The rainfall bars are flat, but the NAPI pieces are not flat because the weights are larger for recent days.

Add a recent event

Now put a storm in the last five days. Because it is recent, those bars sit under large weights, so they dominate the NAPI value.

Add older events too

Keep the recent storm the same, then add a few rainy days around 20 days ago. NAPI increases, but not as much, because old rainfall is discounted.

Parameters without overthinking it

Where the parameters come from.

Rainfall P What it is

The rainfall on each of the 30 previous days.

Where it comes from

A rain gauge, a rainfall record, or a design assumption for antecedent rainfall.

Do you calibrate it?

No. Rainfall is input data. You can test sensitivity, but it should not be tuned to fit one storm.

Evaporation / loss E What it is

The daily amount subtracted before weighting: max(P − E, 0).

Where it comes from

Evaporation data, seasonal assumptions, or the model's event/profile evaporation setup.

Do you calibrate it?

Usually no. Use a defensible value and document it.

Memory factor k What it is

The decay factor that sets how quickly old rainfall loses influence.

Where it comes from

WRAP soil class lookup: class 1 → 0.10, class 2 → 0.50, class 3 → 0.70, class 4 → 0.90, class 5 → 0.99.

Do you calibrate it?

Not normally. Pick it from the soil class. Change it only if the soil classification is wrong or local evidence supports a different assignment.

Good modeling practice: NAPI changes because the preceding weather changes. It is not a separate catchment parameter you refit for every storm.
Useful sensitivity test: Compare a recent event scale versus a past event scale. Same rainfall depth near today usually moves NAPI more than the same rainfall depth three weeks ago.
One-line version: NAPI is a 30-day weighted rainfall average. Rainfall provides the daily bars, k provides the daily weights, and NAPI is the weighted sum.
